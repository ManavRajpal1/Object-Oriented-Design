## 🧱 OOP Fundamentals ➔ [View PDF](Paste your link here)

* **Classes & Objects:** Blueprint and instance relationship forming the foundation of OOP.
* **Enums:** A special type used to define a fixed set of constants.
* **Interfaces:** Contracts that define behavior without implementation.
* **Encapsulation:** Hiding internal state and exposing controlled access.
* **Abstraction:** Showing only essential details while hiding complexity.
* **Inheritance:** Mechanism to reuse code by deriving new classes from existing ones.
* **Polymorphism:** One interface, multiple implementations (compile-time & runtime).

---

## 🔗 Class Relationships ➔ [View PDF](Paste your link here)

* **Association:** General relationship where objects are aware of each other.
* **Aggregation:** Weak "has-a" relationship where lifecycle is independent.
* **Composition:** Strong "has-a" relationship with dependent lifecycle.
* **Dependency:** Temporary relationship where one class uses another.

* **YAGNI Principle:** Don’t build something until it’s actually needed.
